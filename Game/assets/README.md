# Production art library

Generated with the built-in image tool, using the existing Hana illustration as the shared style reference. Each woman has three transparent four-pose strips, ordered by the runtime visual vocabulary. Source PNG alpha is preserved. The native asset loader extracts the cells at load time and builds skeletal motion clips.

Pose order: neutral, wave, explain, folded; shy, laugh, worried, firm; seated, seated_relaxed, affectionate, cuddle.

Backgrounds cover all ten locations. `prompts.json` records the generation prompts and source files. The rejected first Hana 12-up atlas is not used by the game.
