# Game assets for Panel

Generated by `Game/export_panel.py` from the existing story and PNGs. Contains 35 story scenes, four character-specific repair scenes, 48 poses and ten reusable rigid animation clips.

Run `start-game.cmd` to play. `Game/panel_player.py` owns the story integration and uses the unchanged `Game/runtime.py` controller for saves, routes, personality prompts and individual memories. The generic engine remains game-independent.

Each sprite is an extracted cell of the original atlas, represented by one rigid layer. Independent limb deformation is not supported by this conversion. Background paths reference `Game/assets/backgrounds`; include that directory when moving this project. Music remains in `Game/music`.

The old `app/` export is unchanged and has not been rebuilt for this engine.
