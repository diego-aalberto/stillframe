# games/

Installed games live here. Each is either a folder (as in `the-light-we-leave-on/`) or a single `.stillgame` file.
Run `stillframe` to open the library, or `stillframe games/the-light-we-leave-on` to open one directly.

`the-light-we-leave-on` was generated from the legacy story data by `tools/port_legacy_story.py`; edit it by hand from now on.
